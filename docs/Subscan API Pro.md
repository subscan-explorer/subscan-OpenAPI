
Subscan API PRO is a paid direct-Subscan service for customers who need plan-specific quotas or features. New free API
keys are no longer issued through the direct Subscan API Platform; new free integrations should use a PubFi API key and
the PubFi Gateway instead.

PubFi free-route access is a separate product path. A PubFi key, a PubFi `:free` route, and any PubFi Credits are not a
Subscan PRO subscription and should not be described as one.

## Features

- **Higher Quotas**: PRO users can receive higher quotas according to the selected direct plan.
- **Priority Support**: PRO users receive priority support from the Subscan team.
- **Additional endpoints**: Plan availability may include additional endpoints; confirm the current plan terms before
  relying on them.


## Upgrade to PRO

To discuss or manage a direct paid plan, use the current [Subscan API Platform](https://pro.subscan.io/) instructions and
plan terms. The [PubFi Tutorial](https://support.subscan.io/doc-360177) covers the separate free onboarding path.
